# Roadmap

## Phase 1: Data ingestion and structure
- Create a reusable data loading workflow
- Support CSV and Excel uploads
- Validate dataset quality

## Phase 2: Insight generation
- Add summary metrics
- Detect missing values and duplicates
- Generate rule-based business insights

## Phase 3: Dashboard & visuals
- Add Streamlit dashboard components
- Implement charts for sales, profit, and quality issues
- Improve UX and clarity of reporting

## Phase 4: AI-style interaction
- Add dataset Q&A using rule-based logic
- Improve interpretability of insights
- Support exportable report generation

## Phase 5: Portfolio readiness
- Add polished documentation
- Include sample dataset and demo workflow
- Finalize project for scholarships and submissions
